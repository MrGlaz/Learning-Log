### 🔑 1. Identité et Gouvernance

- **[[Microsoft Entra ID]]** : Gère l'accès aux ressources, pilier du **[[RBAC]]**.
    
- **[[RBAC]]** (Role-Based Access Control) : Définit les permissions sur les **[[Management Groups]]** et abonnements.
    
- **[[Azure Policy]]** : Applique des règles de conformité, souvent aidé par les **[[Tags]]**.
    
- **[[Management Groups]]** : Hiérarchie pour gérer plusieurs abonnements.
    
- **[[Tags]]** : Clés-valeurs pour l'organisation et le **[[Cost Management]]**.
    
* [[Localisation]] : point d'ancrage physique des données dans le monde réel

---

### 📦 2. Stockage

- **[[Storage Account]]** : Conteneur global qui héberge le **[[Blob Storage]]** et **[[Azure Files]]**.
    
- **[[Blob Storage]]** : Stockage d'objets avec différents **[[Access Tiers]]**.
    
- **[[Access Tiers]]** (Hot, Cool, Archive) : Optimisation des coûts de stockage.
    
- **[[Redondance Stockage]]** (LRS, GRS, ZRS) : Stratégies de réplication des données.
    
- **[[SAS]]** (Shared Access Signature) : Sécurise l'accès temporaire aux données sans clé maîtresse.
    
- **[[Azure File Sync]]** : Relie vos serveurs locaux à **[[Azure Files]]**.
    

---

### 💻 3. Calcul (Compute)

- **[[Virtual Machines]]** : Déployées dans un **[[VNet]]**, protégées par des **[[Availability Zones]]**.
    
- **[[Availability Sets]]** : Protection contre les pannes matérielles (Update/Fault Domains).
    
- **[[Availability Zones]]** : Protection contre la panne d'un datacenter complet.
    
- **[[VMSS]]** (Scale Sets) : Mise à l'échelle automatique de **[[Virtual Machines]]**.
    
- **[[App Service]]** : Hébergement PaaS, souvent connecté à un **[[VNet]]** via injection.
    
- **[[AKS]]** (Azure Kubernetes Service) : Orchestration de conteneurs complexe.
    
- **[[ACI]]** (Azure Container Instances) : Exécution rapide de conteneurs sans gestion de nœuds.
    

---

### 🌐 4. Réseaux Virtuels (Le "Nervous System")

- **[[VNet]]** : Le socle réseau contenant des **[[Subnets]]**.
    
- **[[VNet Peering]]** : Connecte deux **[[VNet]]** entre eux.
    
- **[[NSG]]** (Network Security Group) : Règles de filtrage (L4) appliquées aux **[[Subnets]]** ou NIC.
    
- **[[ASG]]** (Application Security Group) : Simplifie la gestion des règles de **[[NSG]]**.
    
- **[[Azure Load Balancer]]** : Répartit le trafic (L4) vers des **[[Virtual Machines]]**.
    
- **[[Application Gateway]]** : Équilibreur (L7) avec **[[WAF]]** pour protéger les **[[App Service]]**.
    
- **[[VPN Gateway]]** : Connexion hybride sécurisée via Internet.
    
- **[[ExpressRoute]]** : Connexion hybride privée haut débit.
    

---

### 📊 5. Surveillance et Sauvegarde

- **[[Azure Monitor]]** : Centralise les métriques et les logs envoyés vers **[[Log Analytics Workspace]]**.
    
- **[[Log Analytics Workspace]]** : Analyse les données avec le langage **[[KQL]]**.
    
- **[[Recovery Services Vault]]** : Stocke les données de **[[Azure Backup]]** et **[[ASR]]**.
    
- **[[Azure Backup]]** : Sauvegarde granulaire de fichiers et de **[[Virtual Machines]]**.
    
- **[[ASR]]** (Azure Site Recovery) : Plan de continuité d'activité (DR) entre régions.
